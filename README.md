# Travel CRM

Курсовой проект по дисциплине ПКИС, группа ЭФМО-01-25.

**Тема:** «Создание программного решения для автоматизации процесса управления клиентскими отношениями в туристической компании».

## Назначение

Веб-сервис для работы туристической компании с клиентами: ведение заявок, подбор туров по предпочтениям, управление бронированиями, учёт платежей, история общения и базовая отчётность.

В учебной версии внешние сервисы каталога, бронирования и оплаты заменяются тестовыми заглушками.

## Текущий статус

Подготовлена первая версия документации (0.1 от 26.10.2026). Реализация приложения ещё не начата. Документы являются рабочим проектом: требования и этапы будут уточняться командой и сверяться с материалами преподавателя. Технологический стек и сроки пока не выбраны.

## Совместная работа

Задачи ведутся в [Issues](https://github.com/d1vide/travel-crm/issues). Изменения выполняются в отдельных ветках, сохраняются коммитами и объединяются в main через Pull Request после проверки. Подробности — в [правилах команды](docs/team.md).

Ближайшие шаги: подключить второго участника, обсудить допущения ТЗ, выбрать технологии и разбить проектирование и реализацию на Issues.

## Запуск

Исполняемый код пока отсутствует. Инструкция запуска, тестовые данные и описание конфигурации будут добавлены вместе с основой приложения.
