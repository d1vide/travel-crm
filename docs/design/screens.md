# Экраны и навигация TravelCRM

Схема для текущего MVP. Требования приведены по [ТЗ](../technical-specification.md), оформление — по [дизайн-системе](DESIGN.md). Роли и адреса сверены с `frontend/src/auth/navigation.ts` и `frontend/src/router/index.ts`.

## Доступ к экранам

| Экран | Адрес или раздел | Роли | Требования |
|---|---|---|---|
| Вход | `/login` | Сотрудник до входа | FR-01, FR-09 |
| Профиль | `/profile` | Менеджер, руководитель, бухгалтер | FR-01, #48 |
| Список, создание и карточка клиента | `/clients`, `/clients/new`, `/clients/:id` | Менеджер, руководитель, действия по правам | FR-02, FR-07, FR-09 |
| Список, kanban, создание и карточка заявки | `/requests`, `/requests/new`, `/requests/:id` | Менеджер, руководитель, действия по правам | FR-03, FR-08, FR-09 |
| Каталог | `/tours` | Менеджер, руководитель | FR-04 |
| Подбор, туристы, бронь и отмена | Карточка заявки | Менеджер, руководитель, действия по правам | FR-04, FR-05, FR-09, FR-10, FR-11 |
| Платежи и возвраты по брони | Карточка заявки | Менеджер, руководитель, действия по правам | FR-06, FR-09, FR-12 |
| Общение | Карточки клиента и заявки, рабочее место руководителя | Менеджер, руководитель, действия по правам | FR-07, FR-08 |
| Оплаты и возвраты | `/payments` | Руководитель, бухгалтер | FR-06, FR-08, FR-12 |
| Рабочее место руководителя | `/workspace` | Руководитель | FR-08 |
| Отчёт | `/reports` | Руководитель | FR-08, FR-09 |
| Уведомления | `/notifications` | Менеджер, руководитель | FR-13 |
| Подборка | `/public/selections/:token` | Клиент по ссылке | FR-04 |
| Форма туристов | `/public/tourist-forms/:token` | Клиент по ссылке | FR-09, FR-10 |
| Тестовая оплата | Страница платёжной заглушки по ссылке | Клиент по ссылке | FR-06 |
| Нет доступа / страница не найдена | `/forbidden`, неизвестный адрес | Авторизованный сотрудник | FR-01 |

Ограничения меню действуют и при прямом переходе. Сервер проверяет доступ к данным и определяет доступные действия через `allowed_actions`. Менеджер видит закреплённые за ним заявки. Бухгалтер получает финансовое представление с оплатами и возвратами.

## Эскизы

| Экран | Расположение элементов сверху вниз |
|---|---|
| Вход | По центру форма с email и паролем. Ошибки полей рядом с вводом, кнопка «Войти» внизу. |
| Список клиентов | Заголовок и действие создания → поиск → таблица → пагинация. |
| Карточка клиента | Имя и доступные действия → контакты и заметки → связанные заявки и общение. |
| Список заявок | Заголовок и действие создания → фильтры и переключатель представления → таблица или kanban. |
| Карточка заявки | Заголовок, статус и действия → параметры заявки → подбор, туристы, бронь и финансовые операции → общение и история. |
| Подбор и каталог | Поиск и фильтры → предложения с датами, размещением и стоимостью → выбранные туры и действие выдачи ссылки в карточке заявки. |
| Бронь | Выбранный тур и стоимость → туристы → статус и доступные действия по ответу поставщика и отмене. |
| Платежи и возвраты | В карточке — суммы, статусы и действия по платежу. В финансовом разделе — вкладки платежей и возвратов, фильтры и списки. |
| Общение | Форма с датой, каналом и текстом → записи с именем автора. В рабочем месте руководителя — просмотр по строке заявки. |
| Рабочее место руководителя | Переключатель «Заявки команды / Финансы» → список выбранного раздела. |
| Отчёт | Период и действие построения → четыре показателя: заявки, брони, оплаты, возвраты. |
| Публичные страницы | Заголовок и содержимое конкретной ссылки → карточки туров, поля туристов или результат тестовой оплаты. |
| Профиль и уведомления | Профиль показывает ФИО и рабочие контакты. Уведомления открываются отдельным списком из шапки. |
