Причина #67 соответствует алгоритму [Fetch: добавление Origin](https://fetch.spec.whatwg.org/#append-a-request-origin-header). Исправление не разрешает отсутствующий, `null` или посторонний Origin. Ошибка сети/HTTP выводится как ошибка, без ложного сообщения об успехе.
